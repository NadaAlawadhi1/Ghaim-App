# 🐾 Ghaim – Social Media for Animal Lovers

**Ghaim** is a social media platform built for animal enthusiasts. Users can connect with fellow animal lovers, share experiences, and celebrate the joy of pets and wildlife. The app fosters a vibrant community for discussing animal care, posting photos, and engaging with others who share a passion for animals.

⚠️ **Project Status:** Ghaim is currently under active development.  
Some features — including chatting and notifications — are not yet fully functional or may be temporarily disabled.

## 🌟 Features
- 📝 Create, edit, and delete posts  
- 🖼️ View posts with images  
- ❤️ Like and 💬 comment on posts  
- 🔍 Search for users, with follow/unfollow functionality  
- 👤 User profile page showing bio, posts, and avatar  
- ⚙️ Settings screen to update profile info, app preferences, and privacy options  
- 🔄 Update posts after publishing  
- 🔐 Secure login and sign-up system  
- 🎨 Cute, user-friendly design with smooth UI
